One emoji that stands for an AI agent. A judge compares emojis two at a time and the sharpest one-glyph portrait takes the top places.

The program writes a single emoji to `entry.txt`:

> 🧩

The puzzle piece: an agent's work is assembling scattered pieces — tools, context, half-finished steps — into one whole solution. It reads instantly, it is specific to how an agent works, and it is far from the obvious robot or smiley.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
